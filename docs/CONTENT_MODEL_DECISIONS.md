# Copy and evidence decisions

This guide is built from the pinned MITRE ATLAS snapshot (`data/upstream/atlas/`) plus separate Field Guide editorial overlays (`data/editorial/`). The build script preserves that boundary.

## Decisions to preserve

- The three-case “Who’s directing the attack?” trail is editorial sequencing, not an ATLAS relationship.
- Case titles, event type, canonical narrative, technique names, and case-to-technique relationships come from ATLAS.
- Archive summaries and outcome notes are Field Guide summaries. They should identify their origin in context, not masquerade as quoted ATLAS prose.
- “Patterns” replaces “Recurring” and “named shapes” in reader-facing copy. A pattern can currently have one case; its count must be visible.
- Source rows should identify the source’s route into the guide (“Named by ATLAS” or “Added by this Field Guide”). They should not claim a document is primary unless that has been verified and modeled.
- The source index is named “Cited sources,” not “Original reports.”
- The relevant relationship language is “mapped to,” because the guide is presenting the official ATLAS relationship—not independently asserting every case used a technique in the same way.
